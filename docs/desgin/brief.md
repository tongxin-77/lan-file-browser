# 管理页面设计需求（Brief）

> **已选定：v5-home-theater.html（家庭影院风）作为管理页方案。**

## 产品
LAN File Browser 电脑端管理页：Windows 电脑上运行的 Go 服务自带的本机网页（`http://localhost:8686/`，只能在本机打开）。
用户是普通家庭/个人用户，把电脑里的文件夹共享给自己的 Android 手机 App 浏览、看视频、看图片。

## 页面主要用途
**管理共享文件夹及其权限**：用户可以自己添加、移除共享文件夹，并为每个文件夹设置权限。

## 必须包含的功能区
1. **共享文件夹**（核心）
   - 列表：显示名称（手机上看到的名字）、电脑上的真实路径、大小/文件数、状态（正常 / 路径不存在）
   - 添加文件夹：输入或粘贴路径（如 `D:\Movies`），可选自定义显示名称
   - 每个文件夹的权限（可开关）：
     - 浏览与播放（始终开启，是共享的前提）
     - 下载到手机
     - 从手机上传
     - 删除与重命名
     - 显示隐藏文件
   - 每个文件夹可选择“哪些已配对手机可见”：全部手机 / 指定手机
   - 移除共享（不删除电脑上的文件，文案要说清楚）
2. **配对新手机**：二维码 + 6 位 PIN（5 分钟有效，可刷新）
3. **已配对手机**：设备名、最后访问时间，可吊销
4. **服务状态**：本机局域网 IP、端口 8686、版本号；有新版本时提示

## 示例数据（统一使用）
- 文件夹：
  - 电影 — `D:\Movies` — 1.2 TB，386 个文件 — 下载开
  - 动漫 — `D:\Anime` — 640 GB，2,140 个文件 — 下载开
  - 相册 — `E:\Photos\2025` — 82 GB，9,512 个文件 — 下载开、上传开
  - 工作资料 — `C:\Users\Li\Documents\Work` — 3.4 GB — 仅“小米 14”可见
  - 旧硬盘 — `F:\Backup` — 路径不存在（硬盘未连接）
- 手机：小米 14（2 分钟前）、Pixel 8（昨天 21:40）、老人机 Redmi Note 9（12 天前）
- 服务：192.168.1.5:8686，版本 1.2.0，可更新到 1.3.0
- PIN：482 913

## 技术约束
- 单个自包含 HTML 文件（内联 CSS + 原生 JS），用示例数据，交互可模拟（开关、添加弹窗、吊销确认等）
- **不能依赖任何外部资源**（CDN、Google Fonts、图片外链）：页面由离线局域网服务提供
- 字体只能用 Windows 系统自带字体（如 Microsoft YaHei UI、DengXian 等线、SimSun、FangSong、KaiTi、Segoe UI、Bahnschrift、Cascadia、Consolas、Georgia 等）
- 二维码用内联 SVG 占位绘制即可
- 中文界面，桌面浏览器为主（≥1280px），窄屏可用
