# 手机端 App 设计需求（Brief）

## 产品
LAN File Browser Android App（Flutter 实现）：在家里的局域网内连上电脑，浏览电脑共享的文件夹，看视频（支持自动播放下一集）、看图片。
用户是普通家庭成员，主要场景：躺在床上/沙发上用手机看电脑里的电影、动漫，翻相册。
电脑端管理页已选定“家庭影院”风格（参考 `../v5-home-theater.html`），手机端可以呼应也可以独立，以各版方向说明为准。

## 必须设计的屏幕（每版都要有，竖屏 390×844 手机画框，播放器为横屏 844×390）
1. **连接电脑**：自动发现到的电脑列表（“LI-PC · 192.168.1.5”）、扫码连接按钮、手动输入 IP；首次连接输入 6 位配对码的状态
2. **首页 / 共享文件夹**：电脑名与连接状态、“继续观看”（带进度）、共享文件夹入口（电影、动漫、相册、工作资料）
3. **文件夹浏览**：以“动漫 / 星海旅人 / 第一季”为例；路径导航、排序（名称/时间/大小）、列表与网格切换；视频显示缩略图、时长、观看进度/已看完；子文件夹、图片、其他文件（如 .srt 字幕、.nfo）区分显示
4. **视频播放（横屏）**：播放控制、进度条、字幕/音轨/倍速入口、选集列表（第 1–12 集）、**片尾自动下一集**提示：“5 秒后播放 第 13 集 · 归途”，可取消或立即播放
5. **图片查看**：全屏大图、左右滑动、双指缩放提示、底部缩略图条、图片信息（拍摄时间、尺寸）、下载到手机（仅文件夹允许下载时出现）

## 示例数据（统一使用）
- 电脑：LI-PC，192.168.1.5:8686，已连接
- 共享文件夹：电影（386 项）、动漫（2,140 项）、相册（9,512 项）、工作资料（48 项）
- 继续观看：星海旅人 第 12 集（还剩 6 分钟）、雾港往事（看到 1:12:40 / 2:05:10）
- “星海旅人 / 第一季”内容：`Extras/` 文件夹；`星海旅人 S01E01 启航.mkv` … `S01E12 灯塔.mkv`（每集约 24 分钟，第 1–11 集已看完，第 12 集看到 70%）；`S01E13 归途.mkv`；`星海旅人.S01.chs.srt`；`poster.jpg`；`tvshow.nfo`
- 相册：`E:\Photos\2025` 中的 `IMG_20250612_183015.jpg`（4032×3024，2025-06-12 18:30）
- 权限：相册允许下载

## 技术约束（设计稿）
- 输出单个自包含 HTML 文件，把 5 个屏幕并排/分行展示在手机画框里，可有少量交互演示（如点击切换、下一集倒计时动画）
- **不能依赖任何外部资源**（CDN、Google Fonts、外链图片）；缩略图、海报用 CSS/SVG 色块与排版生成
- 设计稿字体只用 Windows 系统字体（Microsoft YaHei UI、DengXian、Bahnschrift、Segoe UI、Consolas 等）；在 HTML 注释中写明最终 App 建议打包的字体（如思源黑体/HarmonyOS Sans 等开源字体）
- 遵循 Android 手势习惯（返回、底部安全区），触控目标 ≥ 48dp
- 中文界面
