# 电视端 App 设计需求（Brief）

## 产品
LAN File Browser 的 **Android TV 版**（与手机端同一个 Flutter 工程，同一个 APK 适配 TV）：在客厅电视/电视盒子上连上电脑，用遥控器浏览电脑共享的文件夹、看视频（自动下一集）、看图片。
使用方式：坐在 3 米外用 **遥控器方向键（上下左右 + 确认 + 返回 + 菜单）** 操作，没有触屏、没有鼠标。
电脑端管理页为“家庭影院”风格（参考 `../v5-home-theater.html`），手机端设计稿见 `../app/`。

## 必须设计的屏幕（1920×1080 画框，可缩放展示）
1. **连接电脑**：自动发现的电脑列表（“LI-PC · 192.168.1.5”）；电视不能扫码，首次配对用遥控器输入 6 位配对码；或由已配对的手机“投送配对”
2. **首页**：继续观看（带进度）、共享文件夹（电影、动漫、相册、工作资料）、最近添加
3. **文件夹浏览**：以“动漫 / 星海旅人 / 第一季”为例，海报/剧集网格，**遥控器焦点状态**必须清晰醒目（放大、描边或高亮），显示时长与观看进度；字幕、nfo 等非媒体文件弱化或隐藏
4. **视频播放**：播放控制条（遥控器呼出）、进度、字幕/音轨/倍速、选集行；**片尾自动下一集**：“5 秒后播放 第 13 集 · 归途”，焦点默认在“立即播放”，按返回取消
5. **图片查看 / 幻灯片**：全屏大图、左右键切换、自动幻灯片播放、图片信息

## 电视设计规范要点
- 10 英尺界面：正文 ≥ 24px（1080p 画布），标题更大；四周保留约 5% 安全边距（过扫描）
- 每屏都要标出当前焦点项，并在 HTML 中用方向键可实际移动焦点演示（至少文件夹浏览屏）
- 层级浅、横向行为主（类似电视桌面），避免需要精确指点的小控件
- 避免纯白大面积背景（电视上刺眼）

## 技术约束（设计稿）
- 单个自包含 HTML，不依赖任何外部资源；海报、缩略图用 CSS/SVG 生成
- 字体只用 Windows 系统字体；注释中写明最终 App 建议打包的开源字体
- 中文界面
